# Outlook 空き時間検索・会議案内作成

Windows の従来版 Outlook と連携し、複数参加者の空き時間（FreeBusy）を検索して共通空き時間候補を抽出し、会議案内メール／会議作成画面の下書きまで作成できるデスクトップアプリケーションです。

## 主な機能

- **複数参加者の空き時間検索**
  - 日付、検索時間帯、必要時間（15分〜120分）を指定し、選択した参加者の予定ステータス（空き・仮予定・予定あり・外出中・他の場所で作業など）を15分刻みで一覧表示します。
  - 全員が空いている時間帯から、指定した必要時間を満たす共通空き時間候補を抽出します。
- **参加者リストの追加・削除**
  - アプリ画面から参加者の追加・削除ができ、設定はローカルファイルに保存されます。
- **会議案内の作成と Outlook 連携**
  - 抽出した候補日時を選択すると、本文の日時表記と連動します。
  - 「標準の会議案内」「簡潔な会議案内」の定型文切り替えや、場所変更時の本文反映に対応しています。
  - 出席者を解決したうえで Outlook の会議作成画面を表示します（※ 自動送信は行いません）。

## 動作環境

- **OS**: Windows（従来版 Outlook が利用可能な環境）
- **Python**: Python 3.10 以上推奨
- **必要なライブラリ**:
  - `PySide6`
  - `pywin32`
